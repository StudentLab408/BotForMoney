# nadbavkiBot

Telegram-бот учёта надбавок к стипендии для студенческой научно-исследовательской лаборатории.

## Возможности

**Студенты**
- Регистрация (ФИО + группа), изменение данных профиля.
- Заявка за конференцию или мероприятие: выбор из справочника (или добавление новой с датой), проект — кнопкой из своих проектов.
- «Мои заявки»: статусы, суммы, причины отказа; отзыв заявки, пока она на рассмотрении.

**Админы**
- 📥 **Заявки** — очередь на рассмотрение; карточки новых заявок также приходят в личку. Одобрение с выбором суммы (12,5 / 25 / 50 BYN) или отказ с причиной.
- 👥 **Студенты** — список с фильтрами (в проектах, с конференциями, без активности, архив, по группе) и поиском. Карточка студента: проекты, начисления за текущий месяц, история заявок и действия — добавить в проект или убрать, начислить за конференцию/мероприятие, изменить сумму или отменить начисление, назначить админом, перенести в архив.
- 📁 **Проекты** — справочник с участниками. Участник получает 200 BYN каждый месяц, начиная с месяца добавления; месяц, в котором его убрали, уже не оплачивается.
- 🏛 **Конференции** и 🎪 **Мероприятия** — справочник: переименование, дата, подтверждение, объединение дублей, архив.
- 📊 **Отчёт за месяц** и 📄 **два .docx-списка**: официальный (полные суммы) и внутренний (основания, колонка «25% в лабу», итог). Автоматическая рассылка списков за прошлый месяц 8-го числа.

**Расчёт за месяц**: участие в проекте перекрывает остальное; иначе сумма одобренных конференций и мероприятий с лимитом 200 BYN. Начисление за конференцию относится к месяцу одобрения.

**Сохранность данных**
- Всё хранится в SQLite, записи не удаляются: заявки отзываются, отклоняются или отменяются, студенты и справочники уходят в архив.
- Незаконченные формы переживают перезапуск бота.
- Каждую ночь — копия базы в `data/backups` (хранится 30 дней), раз в неделю копия приходит супер-админу.
- Схема базы меняется через миграции Alembic — они применяются автоматически при запуске.

«Одно окно»: бот редактирует одно сообщение-меню, удаляет ответы пользователя в формах и устаревшие меню.

Планы на будущее — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

- `BOT_TOKEN` — токен бота от @BotFather.
- `SUPER_ADMIN_ID` — ваш Telegram ID (можно узнать у @userinfobot).

Остальные переменные (`TIMEZONE`, `WITHHOLD_RATE`, `PROJECT_AMOUNT`, `MONTHLY_CAP`, `AUTO_SEND_DAY`, `AUTO_SEND_HOUR`, `BACKUP_KEEP_DAYS`) можно оставить по умолчанию.

## Запуск в Docker

```bash
cp .env.example .env        # заполните BOT_TOKEN и SUPER_ADMIN_ID
mkdir -p data
docker compose up -d --build
```

После `git pull` пересобирайте образ: `docker compose up -d --build`. Без `--build` запустится старая версия кода.

Контейнер работает от непривилегированного пользователя с UID 1000. База и бэкапы лежат в `./data` на хосте и переживают пересборку контейнера. Если на Linux-сервере бот не может записать базу, один раз выдайте права:

```bash
sudo chown -R 1000:1000 data
```

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

## Разработка

```bash
pip install -r requirements-dev.txt
pytest          # юнит-тесты, миграции и сценарии бота на фейковом Telegram API
ruff check bot tests migrations
ruff format bot tests migrations
```

Изменили модели в `bot/db/models.py` — создайте миграцию:

```bash
python -c "from alembic import command; from bot.db.engine import alembic_config; command.revision(alembic_config('data/dev.db'), message='describe change', autogenerate=True)"
```

## Первый запуск

1. Напишите боту `/start` от аккаунта с `SUPER_ADMIN_ID` и пройдите короткую регистрацию. Права супер-админа появляются после регистрации: они определяются Telegram ID из конфига, а не ролью в базе.
2. Попросите остальных зарегистрироваться через `/start`. Назначить админа можно в «👥 Студенты» → карточка → «👑 Сделать админом».
3. Создайте проекты в «📁 Проекты» и добавьте участников.

Команды для всех: `/start`, `/menu`, `/help`. Админам в списке команд Telegram дополнительно видны `/admin`, `/requests`, `/students`, `/projects`, `/events`, `/report`, `/export`, супер-админу — ещё `/admins`. Команды работают из любого места, даже посреди заполнения формы.
