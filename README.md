# nadbavkiBot

Telegram-бот учёта надбавок к стипендии для студенческой научно-исследовательской лаборатории.

## Возможности

- Самостоятельная регистрация студентов (ФИО + группа), изменение данных профиля.
- Заявки на надбавку за конференции и мероприятия; просмотр своих заявок и их статусов.
- Подтверждение заявок админами с выбором суммы (12,5 / 25 / 50 BYN); проектная надбавка (200 BYN) начисляется админом напрямую.
- Расчёт за календарный месяц: проект перекрывает остальное, иначе сумма конференций и мероприятий с лимитом 200 BYN.
- Два .docx-списка за месяц: **официальный** (полные суммы, без оснований) и **внутренний** (с основаниями, колонкой «25% в лабу» и итогом).
- Автоматическая рассылка списков за прошлый месяц всем админам 8-го числа.
- Отчёт за месяц и активность студентов (кто подаёт заявки, а кто нет).
- «Одно окно»: бот редактирует одно сообщение-меню, удаляет ответы пользователя в формах и устаревшие меню, чтобы чат не засорялся.

Планы на будущее — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

- `BOT_TOKEN` — токен бота от @BotFather.
- `SUPER_ADMIN_ID` — ваш Telegram ID (можно узнать у @userinfobot).

Остальные переменные (`TIMEZONE`, `WITHHOLD_RATE`, `PROJECT_AMOUNT`, `MONTHLY_CAP`, `AUTO_SEND_DAY`, `AUTO_SEND_HOUR`) можно оставить по умолчанию.

## Запуск в Docker

```bash
cp .env.example .env        # заполните BOT_TOKEN и SUPER_ADMIN_ID
mkdir -p data
docker compose up -d --build
```

Контейнер работает от непривилегированного пользователя с UID 1000. База `nadbavki.db` лежит в `./data` на хосте и переживает пересборку контейнера — эту папку удобно бэкапить. Если на Linux-сервере бот не может записать базу, один раз выдайте права:

```bash
sudo chown -R 1000:1000 data
```

## Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

## Разработка

```bash
pip install -r requirements-dev.txt
pytest          # юнит-тесты и сценарии бота на фейковом Telegram API
ruff check bot tests
ruff format bot tests
```

## Первый запуск

1. Напишите боту `/start` от аккаунта с `SUPER_ADMIN_ID` и пройдите короткую регистрацию. Права администратора появляются только после регистрации: они определяются вашим Telegram ID из конфига, а не ролью в базе.
2. В «🛠 Админ-панель → 👑 Управление админами» назначьте остальных админов: перешлите их сообщение боту или укажите Telegram ID. Они должны быть уже зарегистрированы.
3. Студенты регистрируются сами через `/start`.

Команды: `/start` — регистрация или меню, `/menu` — главное меню из любого места, `/help` — справка.

Админам в списке команд Telegram дополнительно видны `/admin`, `/project`, `/report`, `/export`, `/activity`, а супер-админу — ещё `/admins`. Этот список появляется у админа сразу после назначения и пропадает при снятии прав. Команды работают из любого места, даже посреди заполнения формы.
