# Планы на будущее

- **Учёт фактического дохода лаборатории.** Сейчас бот не показывает в отчётах, сколько денег «теоретически» уходит в фонд лаборатории (25%): это расчётная цифра. Удержание видно только во внутреннем .docx-списке. Позже добавим загрузку фактических отчётов (какие суммы реально прошли) и отчётность по ним.
- **Хранение состояния форм между перезапусками.** Сейчас состояние форм и «экранов» в памяти (`MemoryStorage`) — при перезапуске бота незаконченная форма сбрасывается. При необходимости — перейти на Redis/SQLite storage.
- **Миграции БД** (Alembic), когда схема начнёт меняться при уже накопленных данных.
- **Пропуск автоматической рассылки при простое.** Если бот был выключен в момент рассылки 8-го числа, она не повторится после запуска — списки можно сформировать вручную в админ-панели.
